# Backup Config

Folder ini berisi file-file cadangan/arsip konfigurasi lama yang dipindahkan dari direktori aktif agar tidak membingungkan atau dimuat secara otomatis oleh runtime Neovim (misalnya file `after/ftplugin/*_backup*.lua`).

File-file di sini tersimpan dengan aman untuk referensi dan tidak mempengaruhi runtime Neovim yang aktif.
